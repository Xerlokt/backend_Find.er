## v2 Requirements (Milestone v2.0 — Complete)

### Architecture — Layer Isolation (ARCH)

- [x] **ARCH-05**: Domain entities em `src/domain/entities/` não importam nenhuma lib externa (Prisma, Fastify, bcrypt, JWT)
- [x] **ARCH-06**: Repository interfaces em `src/domain/interfaces/` definem contratos de acesso a dados sem implementação (portas de saída)
- [x] **ARCH-07**: Use cases em `src/application/use-cases/` recebem todas as dependências exclusivamente via interfaces e ports — nunca implementações concretas — ✓ Phase 12
- [x] **ARCH-08**: Ports em `src/application/ports/` definem contratos para serviços externos: `IHashPort` (bcrypt), `ITokenPort` (JWT), `IGraphPort` (Neo4j)
- [x] **ARCH-09**: Controllers em `src/adapters/controllers/` orquestram use cases e formatam resposta HTTP sem conter lógica de negócio — ✓ Phase 10–11
- [x] **ARCH-10**: Repository implementations em `src/adapters/repositories/` implementam as interfaces definidas em `src/domain/interfaces/` — ✓ Phase 10–12
- [x] **ARCH-11**: Service adapters em `src/adapters/services/` implementam os ports definidos em `src/application/ports/` — ✓ Phase 10 (BcryptAdapter, JwtAdapter), Phase 12 (Neo4jAdapter)
- [x] **ARCH-12**: Routes em `src/infrastructure/http/routes/` apenas registram endpoints e instanciam controllers — sem lógica de negócio — ✓ Phase 10–12
- [x] **ARCH-13**: Regra de dependência enforced: `domain` não importa nada do projeto; `application` importa apenas `domain`; `adapters` importa `application` + `domain`; `infrastructure` importa todas as camadas — ✓ Phase 13 (scripts/check-deps.ts)

### Test Preservation (TEST)

- [x] **TEST-01**: Todos os testes de integração existentes (41 testes) continuam passando após refatoração — regressão zero — ✓ Phase 12-04
- [x] **TEST-02**: Use cases são testáveis unitariamente sem banco usando mocks Jest das interfaces de domínio — ✓ Phase 13 (6 use-case unit tests)
- [x] **TEST-03**: Repository implementations são testadas contra banco real (Docker Compose) sem mocks — ✓ Phase 11

### Migration Completeness (MIGRATE)

- [x] **MIGRATE-01**: Nenhum arquivo de lógica permanece em `src/modules/` após migração completa — ✓ Phase 13-02 (directory deleted)
- [x] **MIGRATE-02**: Todos os arquivos seguem o mapeamento definido no `plan-architecture.md` — ✓ Phase 13
