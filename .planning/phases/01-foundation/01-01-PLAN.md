Models with exact fields and relations:
- `User`: id (uuid), email (unique), passwordHash (optional), googleId (unique optional), avatarUrl (optional), role (Role), createdAt — has relations to CandidateProfile?, RecruiterProfile?, Message[] (@relation "SentMessages")
- `CandidateProfile`: id (uuid), userId (unique FK→User cascade), name, bio?, lat?, lng?, professionId, skills (String[]), preferredModalities (Modality[]), searchRadiusKm (Int default 50) — has relations to Swipe[], Chat[]
- `RecruiterProfile`: id (uuid), userId (unique FK→User cascade), companyId (FK→Company)
- `Company`: id (uuid), name, logoUrl?, description?, rating (Float default 0), plan (String default "FREE"), planExpiresAt?, credits (Int default 0), createdAt — has relations to RecruiterProfile[], Job[], Chat[], CreditTransaction[]
- `Job`: id (uuid), companyId (FK→Company), title, description, professionId, salaryMin?, salaryMax?, lat?, lng?, modality (Modality), requiredSkills (String[]), expiresAt, isActive (Boolean default true), createdAt — has relations to Swipe[], Chat[]
- `Swipe`: id (uuid), candidateId (FK→CandidateProfile), jobId (FK→Job), direction (SwipeDirection), swipedAt (default now) — @@unique([candidateId, jobId])
- `Chat`: id (uuid), candidateId (FK→CandidateProfile), jobId (FK→Job), companyId (FK→Company), initiatedBy (ChatInitiator), expiresAt?, isActive (Boolean default true), createdAt — has relation to Message[]
- `Message`: id (uuid), chatId (FK→Chat), senderId (FK→User @relation "SentMessages"), content, createdAt (default now), readAt?
- `CreditTransaction`: id (uuid), companyId (FK→Company), amount (Int), reason (String), createdAt (default now)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| .env / .env.example | Secrets must never be committed; .env.example uses placeholder values only |
| Docker network | Containers communicate internally; only necessary ports exposed to host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | .env | mitigate | .env in .gitignore; .env.example has placeholder values only (JWT_SECRET=change-me-in-production) |
| T-01-02 | Elevation of Privilege | postgres_test container | accept | Test DB has no production data; separate port 5433 prevents accidental prod writes |
| T-01-03 | Tampering | prisma/schema.prisma | mitigate | SEC-01: Prisma ORM enforced — no raw SQL with string interpolation in schema or generated client usage |
| T-01-04 | Denial of Service | npm install supply chain | accept | package-lock.json committed; no wildcard version ranges for security-critical packages |
</threat_model>
