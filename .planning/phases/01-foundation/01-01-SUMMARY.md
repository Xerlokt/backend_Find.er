## Deviations

### Auto-fixed Issues

**1. [Rule 1 - Bug] Prisma v7 datasource URL format changed**
- **Found during:** Task 3
- **Issue:** The reference doc schema uses `url = env("DATABASE_URL")` in the datasource block, which is no longer valid in Prisma v7.7.0 — it causes a P1012 validation error
- **Fix:** Removed `url` from schema.prisma datasource; URL is now sourced from `prisma.config.ts` (generated by `npx prisma init`) which already imports dotenv and sets `datasource.url = process.env["DATABASE_URL"]`
- **Files modified:** `prisma/schema.prisma`, `prisma.config.ts`
- **Commit:** 46b10d3

### Deferred Items

**1. Docker Desktop not running — migration not executed**
- **Found during:** Task 2 (docker compose up) and Task 3 (prisma migrate dev)
- **Status:** Docker Desktop Linux engine was not available at execution time (`dockerDesktopLinuxEngine` pipe not found)
- **Impact:** `npx prisma migrate dev --name init` could not run; `prisma/migrations/` directory not created
- **Resolution:** User must start Docker Desktop, then run:
  ```bash
  docker compose up -d
  # wait ~5s
  npx prisma migrate dev --name init
  npx prisma generate
  # Verify test DB:
  DATABASE_URL=postgresql://jobtinder_test:jobtinder_test@localhost:5433/jobtinder_test npx prisma migrate deploy
  ```
- **Prisma client:** Generated successfully to `node_modules/@prisma/client` (does not require DB connection)
